Quick Add — błyskawiczne statusy
Dodanie gry wymaga dziś 7 kroków. Zredukujemy to do 2–3 tapnięć.
🟢 Wysoki impact 🟠 Średni nakład ⚡ Sprint 1

Co zmieniamy
  • Swipe w prawo na karcie gry → quick status (4 przyciski)
  • Tryb "Quick Complete" — 3 pola zamiast 6
  • Sticky CTA "Gram teraz" / "Dodaj do backlogu" na GameScreen
  • Smart defaults — zapamiętana ostatnia platforma
  • Picker platform uwzględnia Switch 2, PS5 Pro i nowy sprzęt
Pliki do zmiany
  • games_status_list_item.tsx — dodać Swipeable
  • games_status_form.tsx — isQuickMode toggle

  • use_games_status_form.ts — AsyncStorage defaults

🟢 Wysoki impact 🟠 Średni nakład ⚡ Sprint 2

  • Znajomy ocenił grę → "Anna oceniła Cyberpunk 2077 — 8/10"
  • Znajomy napisał recenzję → "Piotr napisał recenzję God of War"
  • Nowe zaproszenie do znajomych
  • Zaproszenie zaakceptowane
  • Tygodniowe podsumowanie (pon. 18:00)

  • Streak zagrożony — nie aktualizowałeś 14 dni
Architektura

  • Nowa tabela Prisma: PushToken
  • Nowy moduł NestJS: notifications
  • Triggery w istniejących serwisach (games_status, friends)
  • @Cron — weekly summary co poniedziałek
  • Ustawienia toggle w profilu użytkownika
Trigger flow: Jan.upsertGameStatus(COMPLETED) → sprawdź znajomych Jana → znajdź userów którzy mają tę grę → wyślij push przez Expo Push API Wiadomość: "Jan ukończył Elden Ring i dał ocenę 9/10 ✨" Kliknięcie → deeplink: /games_status_info/[id]

Recommendation Strip — "co zagrać dalej"
Po ukończeniu gry użytkownik aktualizuje status i... co dalej? Aplikacja powinna odpowiedzieć.
🟢 Wysoki impact (długoterm.) 🔴 Wysoki nakład
HomeScreen — nowa sekcja: ┌──────────────────────────────────────────────┐ │ 💡 Co zagrać po Elden Ring? │ │ Oparte na Twoich ukończonych grach │ │ ──────────────────────────────────────── │ │ [Sekiro] [Dark Souls 3] [Nioh 2] ... │ │ │ │ Jan, Anna i Piotr polecają Sekiro │ │ po Elden Ring jako "next game" 🎮 │ └──────────────────────────────────────────────┘
Algorytm rekomendacji
  • Weź 5 ostatnio ukończonych gier
  • Sprawdź ich gatunki (Action RPG, Soulslike)
  • Znajdź gry z tymi gatunkami, których nie ma na liście
  • Sortuj: ocena znajomych → popularność HLTB
  • IGDB: pole similar_games — gotowy algorytm kuratorski
"Znajomi też grali w X"
  • Co grali znajomi w 30 dni po ukończeniu tej gry?
  • Najczęstszy "next game" po danej grze
  • Nowe query w API: compareWithFriend
  • "Odkryj gatunek" — raz na miesiąc ekspansja poza strefę komfortu

Oceny zewnętrzne — Metacritic i OpenCritic
Jedna statystyka której brakuje: "co mówią krytycy i gracze z dużych serwisów o tej grze?" — bez wychodzenia z appki.
🟢 Wysoki impact 🔵 Niski nakład
GameScreen — nowa sekcja "Oceny": ┌──────────────────────────────────────┐ │ 📊 Oceny │ │ ──────────────────────────────── │ │ 🎮 Gracze (Game Critique): 8.2/10 │ │ Twoja ocena: 9/10 │ │ │ │ 🎬 Krytycy: │ │ [MC] Metacritic 92/100 │ │ [OC] OpenCritic 94/100 │ │ │ │ ⏱ HLTB Main Story: ~55h │ └──────────────────────────────────────┘
Źródła danych
  • IGDB: pole aggregated_rating + external_games (cat. 8 = Metacritic)
  • OpenCritic: publiczne API (topCriticScore)
  • Pobierane przy istniejącym UpdateGameData
  • Cache w bazie — nie fetch na żywo
Zmiany w kodzie
  • Prisma: pola metacriticScore?, openCriticScore? w modelu Game
  • UpdateGameDataHandler — pobierz przy update
  • GameScreen: komponent GameExternalScores
  • Kolorowanie: ≥80 zielony, 60–79 żółty, <60 czerwony
